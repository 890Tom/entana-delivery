# Security Policy

## Supported versions

The project is pre-1.0: only the latest commit on `main` and the latest tagged release receive security fixes.

## Reporting a vulnerability

Please **do not open a public issue**. Report privately through GitHub: _Security_ tab, then _Report a vulnerability_ (private vulnerability reporting). If that is unavailable, contact the maintainer through the email address on the GitHub profile.

Please include what you found, the steps to reproduce it, the affected version or commit, and the impact you expect.

You can expect an acknowledgement within 7 days and a status update within 30 days. This is a volunteer project: these are targets, not guarantees.

## Scope and data

- The repository must never contain secrets or real personal data. If you find some, report it the same way.
- Customer data handled by a deployed instance is the responsibility of the person operating that instance.
